# Nine Lives Gang plan

Read by Richard's project portal on every push to this branch and shown on the Nine Lives Gang card to everyone he has invited.
Plain words only: no repo names, usernames, file paths, links or commit IDs. Rules: the project's working rules, "Portal" section.

This version is an experiment: Richard chose what makes the game its own, then asked an AI assistant to make every other design call and build the whole game, so it can be compared with the version Richard directs himself.

## Design

- [x] Set the premise: a gang of street cats after what the human carried in
- [x] Decide what makes it different from Heisty Spideys
- [x] Decide the engine: roll a handful of dice and read the highest one
- [x] Design the cats: four ways to do things (sneaky, sweet, savage, streetwise) and two instincts each
- [x] Decide how the prize works: something delicious, something fun, or a box
- [x] Decide what "at all costs" means: push your luck, cattitude and nine lives
- [x] Design the house and the ways in
- [x] Design getting caught: shooed out with a broom, or scooped up for a cuddle
- [x] Plan one-shots and the campaign
- [x] Settle the table: 3 to 5 players, about two hours, ages 8 and up, slapstick
- [x] Set the art direction
- [x] Decide on the online version
- [x] Check the name
